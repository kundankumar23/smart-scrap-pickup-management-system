# ♻️ Smart Scrap Pickup Management System

A full-stack MERN application designed to streamline the scrap collection process by connecting customers, collection agents, and administrators through a centralized digital platform.

The system enables users to schedule scrap pickups, track request status, manage recycling operations, and improve waste collection efficiency through a modern web-based solution.

## 🚀 Features

### Customer Module

* User Registration & Authentication
* Secure Login System
* Schedule Scrap Pickup Requests
* Track Pickup Request Status
* View Pickup History

### Agent Module

* Agent Authentication
* Manage Assigned Pickup Requests
* Update Pickup Status
* View Customer Details

### Admin Module

* Admin Dashboard
* Manage Users and Agents
* Manage Pickup Requests
* Monitor System Activities
* Scrap Category Management
